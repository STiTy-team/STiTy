`loop_judge` 런들이 낸 최종 test 점수를 한자리에 모은 것이다. 출처는 각 런의
`final_report.md` 이고, 여기서는 최종 점수와 지연 구간별 점수만 옮겼다.
2026-09-19 기준.

지표는 `H_set` 이고 **테스트 분할 크기가 런마다 다르다** — judge13~19 는 200문장 / 짝 1787,
judge20 은 296 / 2670, judge21·23 은 660 / 6197 이다. 같은 열에 놓고 Δ 는 비교할 수 있지만
절대값은 분할이 다르면 비교가 안 된다(오라클도 0.6596 / 0.6576 / 0.6549 로 갈린다).

## 읽을 때 주의

- **judge20 은 테스트 문장 수가 296 이라** 다른 런과 절대값을 비교할 수 없다. Δ 는 비교 가능하다.
- **judge21 의 `curve.json` 은 합본 실험 값으로 덮였다.** 근소 기각 편집을 재느라
  `--run-id judge21` 로 `--score-only` 를 돌렸고, 그때 산출물이 채택본 값을 밀어냈다. 위 표의
  judge21 수치는 **런 로그**(`logs/judge21.log`, 01:29:07 줄)에서 가져온 것이다. 산출물이 덮여도
  로그는 남는다 — 로그를 지우지 않는 규칙이 이 자리에서 값을 했다.
- **judge08 은 오라클이 0.5595 로 다르다.** 라벨 정의가 다른 시기의 런이라 나머지와
  같은 축이 아니다. 채택된 개정이 없어 채택본이 곧 v0 다.
- 최종 test 를 돌리지 않은 런(judge03~judge07, judge09~judge12, judge14, judge17, judge18)은
  여기 없다. 그 런들의 dev 단계 채택 이력은 각 런의 `history.json` 에 있다.
